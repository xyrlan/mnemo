- `extraction.provider` accepts `grok-cli`: mnemo's own model calls (extraction, briefings, judges) run through `grok --prompt-file … --output-format json` with Grok's hooks off, so a machine with only Grok Build needs no `claude` binary. With the provider left at its default, it follows the CLI the process drives: `grok-cli` under `MNEMO_AGENT=grok` or inside a Grok session, `claude-cli` otherwise.
