- **`mnemo doctor` says when a project's auto-memory `MEMORY.md` is longer
  than Claude Code loads.** Claude Code loads only the first 200 lines or
  25,000 characters of the index at session start, and says so to the model
  rather than to you. The new check lists each such index with its lines,
  characters and bytes, the limit it crosses, and how many index entries sit
  past the cut; it is silent while every index fits, and takes a few
  milliseconds. (#573)
