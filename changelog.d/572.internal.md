- **`tools/audit_stub_args.py` finds the test stubs production code calls,
  and checks each call against the function the stub stands in for.** Loaded
  into a suite run with `-p tools.audit_stub_args --stub-audit=FILE`, it
  records every call from `src/` or `tools/` into a function written under
  `tests/`. Stubs set by `monkeypatch.setattr` or `mock.patch` are checked
  against the real function's signature and annotations. Stubs handed in as
  arguments are checked against the default or the function `main` wires in.
  The full suite reaches 2,048 such call sites, and none of them passes
  anything the real function refuses. Run against the code before #562, it
  flags `historical_yield`'s `path=str (wants Path)`. A new test also runs
  the `session_end` hook's queue sweep with the real reader and detector.
  The old test fed that sweep strings, and the hook swallows errors. (#572)
