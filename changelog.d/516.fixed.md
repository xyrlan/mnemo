- **A contract's `files` now admits the paths file-routed web frameworks
  use.** `mnemo dispatch --contract` refused any entry with `(`, `)`, `+`,
  `@` or `$` as prose, which ruled out every path under a Next.js route
  group (`src/app/(dashboard)/…`), SvelteKit's `+page.svelte`, Next.js
  parallel routes (`@modal`) and Remix's `$id.tsx`. Spaces, semicolons and
  backticks are still refused. Landing also matches a listed path literally
  before it treats the path as a glob. Before, fnmatch read Next.js's `[id]`
  as a one-character class, so a piece's exposed signature in
  `app/[id]/page.tsx` was reported missing. (#516)
