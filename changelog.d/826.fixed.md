- **When Claude Code refuses a dispatched child's worktree as untrusted, `mnemo dispatch` now says where to accept the trust prompt.** Claude Code 2.1.321 refuses `claude --bg` in a workspace nobody trusted: "Workspace not trusted. Run `claude` in <worktree> once and accept the trust prompt, then retry." Dispatch then removes that worktree and its branch, so the folder the message names is gone before you read it. The error now adds that Claude Code trusts a worktree through its checkout, and names the checkout to run `claude` in once. Measured on 2.1.321: a worktree of a trusted checkout starts, inside the checkout's folder and outside it (every dispatch tree sits beside its checkout), so dispatch meets the refusal only from a checkout Claude Code was never opened in. A fresh repository is refused even inside a trusted folder or a trusted worktree. `tools/measure_bg_trust.py` measures each case without writing Claude Code's trust state, and the `live_claude` suite, which could no longer start a child, runs again on 2.1.321.
