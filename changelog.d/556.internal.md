- **`tools/measure_dispatch_outcomes.py` reads what every `claude --bg` job
  delivered, dispatched or not, without a model.** It finds each background
  session by the `sessionKind: "bg"` Claude Code writes into its transcript,
  so jobs Claude Code has since pruned from `~/.claude/jobs` still count. It
  splits them into mnemo-dispatched children (issue, piece, twin, read-only)
  and plain jobs, and for each reads the PR (including those `mnemo deliver`
  opened, by the child's branch), whether it merged and how fast, the check
  runs on the commit the child handed off and on the last one, who fixed a red
  hand-off, commits made after the child's last turn, `pr-follow` wakes,
  rate-limit resumes, human input, the parent's notice for the first stop,
  output tokens, and whether any mnemo hook or MCP call reached it. It also
  counts #556's "hands-off" outcome, and `--size` sizes the two-arm dispatch vs
  plain `claude --bg` study from it. It is the zero-token baseline for that
  study. (#556)
