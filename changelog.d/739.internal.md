- **CI runs the suite with `pytest-xdist`, one worker per CPU.** It ran in
  one process on runners with four, and the serial Windows job set every
  run's wall time. `tools/measure_ci_jobs.py` reports each job's queue and run
  time over a workflow's recent runs, for comparing before and after. A bare
  `pytest` stays serial; add `-n auto` locally for the same speedup. (#739)
