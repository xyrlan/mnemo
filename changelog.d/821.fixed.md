- **`mnemo migrate-worktree-briefings` no longer turns a move into a copy on
  a sync satellite, and cleans up after the ones that already did.** A
  satellite may add files but never take a tracked one away, so the next
  sync published the new canonical briefing and restored the original: each
  briefing then existed under both names on every machine, and every re-run
  — on either machine — reported `collision: skipped`. On a satellite the
  command now moves nothing, says the move has to run on the primary (by
  name) and exits 1; `--dry-run` still previews, and `mnemo doctor`'s hint
  there names the primary instead of printing `Run:`. On the primary, or a
  vault without sync, a source whose target already holds the same bytes is
  the leftover of an earlier move: it is removed and its citations repointed,
  as for a move. A source whose content differs is still skipped and
  reported as a collision. (#821)
