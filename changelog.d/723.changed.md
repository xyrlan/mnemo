- **On Windows, a dispatched child now runs below your CPU priority.** It used
  to run at normal priority, the same as you. One child running a test suite
  with a worker per core took a 16-thread workstation to 100% and made the
  desktop sluggish. The dispatcher now marks the child in its settings file,
  and mnemo's `SessionStart` hook lowers the child's own `claude.exe` session
  to below-normal before doing anything else. Everything the session starts
  afterwards inherits that priority. The hook runs again when the child is
  woken, so a woken child is lowered too. The shared daemon and pty host stay
  at normal, and so do interactive sessions. Set `dispatch.childPriority` to
  `"normal"` to opt out. A failure to lower is logged and changes nothing
  else. macOS, Linux and Grok children are unchanged for now. (#723)
