`mnemo sessions` now shows the dispatch children it was hiding. The queue
scoped by exact directory, so a maintainer running it in their repo never saw
the sessions dispatched from it — every child lives in a `<repo>-wt-<issue>`
worktree beside the repo, which never matched. On a real machine that printed
an empty queue while four sessions waited, one blocked for five hours. A repo
and its dispatch worktrees are now one queue, and an empty scoped listing
names how many sessions are elsewhere instead of reading as "nothing is
running".
