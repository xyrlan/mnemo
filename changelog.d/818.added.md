- **`mnemo dispatch --advisor <model>` gives children Claude Code's advisor tool, and `--twins --advisor` measures whether it pays.** It is off unless named. With it, each child is spawned with `--advisor <model>` right after `--model`; without it, the command and the child's settings file are byte-identical to before. A contract piece may carry its own `advisor:`, which wins over the flag the way `model:` does. The value is one model token, checked like `model:`. Measured on Claude Code 2.1.321: a background child whose advisor ranks below its model starts anyway, keeps the flag and gets no advisor, with no warning. So mnemo refuses a pair of aliases in the wrong order (`--model opus --advisor sonnet`) before anything spawns, and refuses `--advisor` on Grok. `mnemo session` and `mnemo sessions --json` show the advisor read back from `respawnFlags`. `mnemo dispatch <n> --twins --model sonnet --advisor opus` runs one issue as two blind arms on the same prompt: one Sonnet twin consulting Opus, one Opus twin alone. `tools/measure_advisor_pairs.py` prints for each pair the preferred arm, each arm's tokens and API-price cost (advisor calls priced at the advisor's own rate), its wall time and its advisor call count. It ends with a verdict against a bar fixed before the first pair. mnemo recommends no advisor until that verdict is positive. (#818)
